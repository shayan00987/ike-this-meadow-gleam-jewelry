# Meadow Gleam Jewelry website

Responsive six-page static website inspired by the Instagram screenshot supplied.

Pages: `index.html` (Home), `shop.html` (Shop All), `rings.html`, `necklaces.html`, `about.html`, `contact.html`. Shared files: `styles.css`, `script.js`; images and generated logo are in `assets/`.

Open `index.html` to preview. For GitHub Pages, upload all files and the complete `assets` folder to the repository root.

The logo is a generated concept. Product photos are crops from the supplied screenshot and are demo placeholders; replace them with approved high-resolution product photos. Product names/prices/availability are illustrative and need confirmation. Configure the shop's verified WhatsApp number in `script.js`. This is a showcase/enquiry website, not a payment checkout.
